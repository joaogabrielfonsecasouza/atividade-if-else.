# 💻 Atividades de Estruturas Condicionais em C

Este repositório reúne exercícios práticos desenvolvidos durante meus estudos de **Lógica de Programação**, no curso de Bacharelado em Sistemas de Informação.

O objetivo é aprimorar meus conhecimentos em Linguagem C, desenvolver o raciocínio lógico e praticar a resolução de problemas por meio de estruturas condicionais.

## 📚 Conteúdos abordados

- Estruturas condicionais `if`, `else if` e `else`
- Operadores relacionais e lógicos
- Estruturas condicionais aninhadas
- Entrada e saída de dados
- Manipulação de variáveis
- Resolução de problemas

## 🛠️ Tecnologias utilizadas

- **Linguagem:** C
- **Editor:** Visual Studio Code
- **Compilador:** GCC
- **Versionamento:** Git e GitHub

## 🚀 Como executar

Para executar os exercícios, é necessário ter o GCC instalado e configurado.

### 1. Clone o repositório

```bash
git clone https://github.com/joaogabrielfonsecasouza/atividade-if-else..git
```

### 2. Acesse a pasta do projeto

```bash
cd atividade-if-else.
```

### 3. Compile a atividade desejada

```bash
gcc atividade1.c -o atividade1
```

### 4. Execute o programa

**Windows (PowerShell):**

```powershell
.\atividade1.exe
```

**Linux ou macOS:**

```bash
./atividade1
```

Para executar outra atividade, substitua `atividade1` pelo número correspondente.
